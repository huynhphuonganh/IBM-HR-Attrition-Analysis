# 🧠 IBM HR Attrition Analysis

## 1️⃣ Introduction  
This project focuses on analyzing and predicting employee attrition within IBM’s HR dataset.  
Using data science methods, the goal is to identify key factors influencing employee turnover and build a predictive pipeline for HR decision-making.

## 3️⃣ Data Analysis Process  
1. **Data Cleaning:** handled missing values, encoded categorical features, normalized numerical ones, and used VIF (Variance Inflation Factor) to ensure model stability and interpretability.
2. **Exploratory Data Analysis (EDA):** used visualization tools to understand trends in attrition.  
3. **Model Building:** trained multiple models (Logistic Regression, Random Forest, etc.) to predict attrition.  
4. **Evaluation:** compared models based on accuracy, precision, recall, and ROC-AUC score.  

---

## 4️⃣ Results and Insights  
- Identified key drivers of employee attrition (e.g., job satisfaction, years at company, income).  
- Best-performing model achieved high accuracy and interpretability.  
- Built a clear visualization dashboard for HR insights.  

---

## 5️⃣ Conclusion  
This project demonstrates how data science techniques can support HR departments in predicting and reducing employee attrition.  
By integrating predictive analytics into HR decision-making, organizations can retain key talent and improve workforce stability.
